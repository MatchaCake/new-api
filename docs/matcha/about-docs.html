抹茶公益站 使用文档

从注册到第一次成功调用，跟着做大约 5 分钟。本站兼容 OpenAI、Claude、Gemini 三种接口格式，大部分 AI 工具只要换个地址和 Key 就能用。

1. 先认识 4 个词

名词是什么
API Key（令牌）相当于你的“通行证 + 钱包钥匙”。工具拿着它来调用模型，费用从你的账户余额里扣。不要发给别人，泄露了就去控制台删掉重建。
Base URL（接口地址）告诉工具“去哪里找模型”。本站是 https://router.matchacake.net/v1。有的工具只要填到域名，见第 3 节。
模型名你要用哪个模型，必须一字不差地填写，包括前面的 antigravity/、devin/、openai/ 前缀。
分组创建令牌时选择。不同分组能用的模型不同（见第 6 节）。选错分组是“模型不存在”报错最常见的原因。

2. 快速开始（4 步）

  1. 注册并登录
    打开 注册页面，用户名 + 密码即可注册，然后登录进入控制台。
  2. 准备额度
    新账号默认余额为 0，需要先在控制台左侧「钱包」充值或使用兑换码。支持支付宝、微信、USDT，最低 $1 起，实际支付金额以钱包页显示为准。
  3. 创建 API Key
    进入控制台「API 密钥」，点「创建 API 密钥」：
    • 名称随便填，比如 我的电脑；
    • 分组：想用更多模型（Claude、GPT 等）选 vip；只用基础模型选 default；
    • 额度可以设上限，防止被盗刷；不确定就勾选“无限配额”，它仍然只会花你账户里的余额。
    创建后点这一行右侧的「⋯」→「复制密钥」，得到一串 sk- 开头的 Key。
  4. 发起第一次调用
    把下面命令里的 sk-xxxx 换成你的 Key，粘贴到终端（macOS 的“终端”、Windows 的 PowerShell 都可以）运行：
curl（macOS / Linux） 
curl https://router.matchacake.net/v1/chat/completions \
  -H "Authorization: Bearer sk-xxxx" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "antigravity/gemini-3-flash",
    "messages": [
      {"role": "user", "content": "你好，请用一句话介绍你自己"}
    ]
  }'
Windows PowerShell 
$headers = @{ "Authorization" = "Bearer sk-xxxx" }
$body = @{
  model = "antigravity/gemini-3-flash"
  messages = @(@{ role = "user"; content = "你好，请用一句话介绍你自己" })
} | ConvertTo-Json -Depth 5
$r = Invoke-RestMethod -Uri "https://router.matchacake.net/v1/chat/completions" `
  -Method Post -Headers $headers -ContentType "application/json; charset=utf-8" `
  -Body ([System.Text.Encoding]::UTF8.GetBytes($body))
$r.choices[0].message.content

看到类似下面的结果就成功了，choices[0].message.content 就是模型的回答：

{
  "object": "chat.completion",
  "model": "gemini-3-flash",
  "choices": [{
    "index": 0,
    "message": {"role": "assistant", "content": "你好！我是一个 AI 助手……"},
    "finish_reason": "stop"
  }],
  "usage": {"prompt_tokens": 8, "completion_tokens": 27, "total_tokens": 35}
}
不想敲命令？登录后控制台里的「游乐场」可以直接在网页里选模型聊天，用来确认账号和额度没问题。

3. 接入常用工具

不同工具对“地址要不要带 /v1”的要求不一样，照下面填就行。

省事的办法：「API 密钥」列表里点 Key 右侧的「⋯」，「聊天」子菜单可以一键导入 Cherry Studio、DeepChat 等工具，「CC Switch」可以一键配置 Claude Code / Codex，省去手动填写。

Cherry Studio

  1. 设置 → 模型服务 → 添加，提供商类型选 OpenAI；
  2. API 密钥：sk-xxxx；API 地址：https://router.matchacake.net（不用加 /v1，软件会自动补）；
  3. 点「管理」拉取模型列表，勾选要用的模型，再点「检查」测试连通。

Chatbox

  1. 设置 → 模型提供方 → 添加，选择 OpenAI API 兼容；
  2. API 主机：https://router.matchacake.net，API 路径：/v1/chat/completions；
  3. API 密钥填 sk-xxxx，模型名手动填写或点获取，例如 antigravity/gemini-3-flash。

Claude Code

Claude Code 走 Claude 格式接口，地址不要带 /v1。建议用 vip 分组的 Key，可选的 Claude 模型更多（default 分组只有 antigravity/claude-* 两个）。在终端里先设置环境变量再启动：

macOS / Linux 
export ANTHROPIC_BASE_URL="https://router.matchacake.net"
export ANTHROPIC_AUTH_TOKEN="sk-xxxx"
export ANTHROPIC_MODEL="devin/anthropic/claude-opus-5-5"
export ANTHROPIC_DEFAULT_HAIKU_MODEL="antigravity/gemini-3-flash"
claude
Windows PowerShell 
$env:ANTHROPIC_BASE_URL = "https://router.matchacake.net"
$env:ANTHROPIC_AUTH_TOKEN = "sk-xxxx"
$env:ANTHROPIC_MODEL = "devin/anthropic/claude-opus-5-5"
$env:ANTHROPIC_DEFAULT_HAIKU_MODEL = "antigravity/gemini-3-flash"
claude

模型可以换成模型广场里任意一个你分组能用的模型。嫌每次设置麻烦，可以用 CC Switch 管理（「API 密钥」页 Key 右侧「⋯」→「CC Switch」一键导入）。

Codex（OpenAI Codex CLI）

编辑 ~/.codex/config.toml（Windows 在 C:\Users\你的用户名\.codex\config.toml），加入：

model = "openai/gpt-6-sol"
model_provider = "matcha"

[model_providers.matcha]
name = "Matcha"
base_url = "https://router.matchacake.net/v1"
env_key = "MATCHA_API_KEY"
wire_api = "responses"

然后设置环境变量 MATCHA_API_KEY=sk-xxxx 再运行 codex。openai/ 开头的模型需要 vip 分组。启动时如果提示“Model metadata … not found”，可以忽略，不影响使用。

其他 OpenAI 兼容工具

沉浸式翻译、LobeChat、OpenCat、各类插件等，只要支持“自定义 OpenAI 接口”，一般按这个规律填：

  • 让你填 Base URL / API 地址：https://router.matchacake.net/v1；
  • 让你填 完整请求地址：https://router.matchacake.net/v1/chat/completions；
  • 让你填 API Host / 服务器，且工具会自己拼 /v1：https://router.matchacake.net。

填错了也不要紧：测试时如果返回一大段网页代码（HTML），或者报 404，基本就是 /v1 多了或少了，换一种试试。

4. 用代码调用

建议把 Key 放在环境变量里，不要直接写进代码、更不要提交到 GitHub。下面为了好懂直接写了 sk-xxxx，记得替换。

Python（OpenAI 官方 SDK）

先安装：pip install openai

from openai import OpenAI

client = OpenAI(
    base_url="https://router.matchacake.net/v1",
    api_key="sk-xxxx",  # 换成你的 Key
)

resp = client.chat.completions.create(
    model="antigravity/gemini-3-flash",
    messages=[
        {"role": "system", "content": "你是一个乐于助人的助手。"},
        {"role": "user", "content": "你好，请用一句话介绍你自己。"},
    ],
)
print(resp.choices[0].message.content)

Python 流式输出（像打字一样逐字返回）

from openai import OpenAI

client = OpenAI(base_url="https://router.matchacake.net/v1", api_key="sk-xxxx")

stream = client.chat.completions.create(
    model="antigravity/gemini-3-flash",
    messages=[{"role": "user", "content": "写一首关于抹茶的四行小诗"}],
    stream=True,
)
for chunk in stream:
    if chunk.choices and chunk.choices[0].delta.content:
        print(chunk.choices[0].delta.content, end="", flush=True)
print()

Node.js（OpenAI 官方 SDK）

先安装：npm install openai，把下面代码保存为 demo.mjs，运行 node demo.mjs：

import OpenAI from "openai";

const client = new OpenAI({
  baseURL: "https://router.matchacake.net/v1",
  apiKey: "sk-xxxx", // 换成你的 Key
});

const resp = await client.chat.completions.create({
  model: "antigravity/gemini-3-flash",
  messages: [{ role: "user", content: "你好，请用一句话介绍你自己。" }],
});
console.log(resp.choices[0].message.content);

多轮对话

模型本身不记得上一句话。想让它“记住”，要把之前的问答按顺序一起发过去：

messages=[
    {"role": "system", "content": "你是一个编程助手。"},
    {"role": "user", "content": "什么是递归？"},
    {"role": "assistant", "content": "递归就是函数调用自己……"},
    {"role": "user", "content": "给我一个 Python 的例子"},
]

历史越长，每次消耗的 token 越多，费用也越高。

5. HTTP API 说明

基础信息

项目说明
接口根地址https://router.matchacake.net（OpenAI 格式路径都以 /v1 开头）
协议HTTPS，请求和响应都是 JSON，编码 UTF-8
鉴权请求头 Authorization: Bearer sk-xxxx；Claude 格式也可用 x-api-key: sk-xxxx；Gemini 格式也可用 x-goog-api-key: sk-xxxx
请求头Content-Type: application/json

可用接口

接口方法与路径用途
模型列表GET /v1/models列出当前 Key 所在分组能用的模型
对话（OpenAI 格式）POST /v1/chat/completions最通用，绝大多数工具都用它
Responses（OpenAI 新格式）POST /v1/responsesCodex 等新工具使用
对话（Claude 格式）POST /v1/messagesClaude Code、Anthropic SDK 使用
对话（Gemini 格式）POST /v1beta/models/{模型名}:generateContentGoogle Gemini SDK 使用
图片生成POST /v1/images/generationsopenai/gpt-image-* 系列（需 vip 分组），返回 base64 图片

不论用哪种格式，模型名都一样，计费也一样。

对话接口常用参数

参数必填说明
model是模型名，必须与模型广场完全一致
messages是消息列表，每条有 role（system 设定 / user 用户 / assistant 模型）和 content
stream否true 时逐段返回（流式），默认 false 一次性返回
temperature否随机程度，越大越发散；不填用模型默认值
max_tokens否回答最多生成多少 token，可用来控制费用

流式响应长什么样

设置 "stream": true 后，服务器会一段一段地推送 data: 开头的行，最后以 data: [DONE] 结束。把每段 delta.content 拼起来就是完整回答：

data: {"object":"chat.completion.chunk","choices":[{"index":0,"delta":{"role":"assistant","content":"1，2，3！"}}]}

data: {"object":"chat.completion.chunk","choices":[{"index":0,"delta":{"content":""},"finish_reason":"stop"}],"usage":{"prompt_tokens":4,"completion_tokens":6,"total_tokens":10}}

data: [DONE]

Claude 格式示例

curl https://router.matchacake.net/v1/messages \
  -H "x-api-key: sk-xxxx" \
  -H "anthropic-version: 2023-06-01" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "antigravity/gemini-3-flash",
    "max_tokens": 1024,
    "messages": [{"role": "user", "content": "你好"}]
  }'

用 Anthropic 官方 SDK 时，base_url 填 https://router.matchacake.net（不带 /v1）。

Gemini 格式示例

curl "https://router.matchacake.net/v1beta/models/antigravity/gemini-3-flash:generateContent" \
  -H "x-goog-api-key: sk-xxxx" \
  -H "Content-Type: application/json" \
  -d '{"contents": [{"parts": [{"text": "你好"}]}]}'

查询可用模型

curl https://router.matchacake.net/v1/models \
  -H "Authorization: Bearer sk-xxxx"

6. 模型、分组与计费

看有哪些模型

最准确的是顶部「模型广场」，那里有每个模型的价格和可用分组；也可以用上面的 /v1/models 接口查询。模型会随上游情况增减，以模型广场为准。

分组

分组能用什么
default基础线路，主要是 antigravity/ 开头的模型（Gemini 系列、Claude、gpt-oss 等少量模型）
vip全部模型，包括 devin/、openai/ 开头的 Claude、GPT、DeepSeek、Kimi、GLM、Grok 以及图片模型

两个分组目前价格倍率相同（都是 1 倍），所以一般直接选 vip 就好。分组是跟着 Key 走的：同一个账号可以建多个不同分组的 Key。

怎么计费

  • 按实际用量扣费：输入多少、输出多少 token 就扣多少，每个模型的单价见模型广场；
  • 站内余额以美元（$）显示；
  • 每次调用的花费可以在控制台「使用日志」里查到；
  • 本站目前没有对单个用户设置每分钟请求次数限制，但上游线路繁忙时可能会临时返回 429（见下一节）。

7. 报错怎么办（错误码）

出错时返回内容一般是这样，看 message 就知道原因：

{"error": {"code": "model_not_found", "message": "分组 default 下模型 gpt-4o 无可用渠道（distributor） (request id: …)", "type": "new_api_error"}}
状态码常见提示是什么意思 / 怎么办
401Invalid token / 无效的令牌Key 填错、多复制了空格、Key 已删除或已禁用；令牌设置的额度用完后也会变成这个错误。去「API 密钥」页检查状态，必要时调高令牌额度后重新启用，或新建一个。
403用户额度不足账户余额用完了，去「钱包」充值或兑换。
403令牌无权访问该模型创建 Key 时开启了“模型限制”，而请求的模型不在列表里。编辑 Key 放开限制即可。
429model_cooldown / cooling down这个模型的上游线路暂时繁忙。等一会儿再试，或换一个模型。
503model_not_found：分组 xxx 下模型 xxx 无可用渠道模型名写错，或你的 Key 所在分组不能用这个模型。对照模型广场检查拼写（包括前缀），或换 vip 分组的 Key。
400 / 5xx上游返回的错误多数是上游线路临时问题，稍后重试或换模型。持续出现请把 request id 发给站长。
返回一段 HTML以 <!doctype html> 开头地址填错了，通常是少了 /v1。

8. 常见问题

注册了为什么不能用？

新账号余额是 0，需要先在「钱包」充值或用兑换码，才能调用模型。

Base URL 到底要不要加 /v1？

写代码（OpenAI SDK）、大多数工具的“API 地址”：加 /v1。Claude Code、Anthropic SDK、Cherry Studio、Chatbox 的“API 主机”：不加。拿不准就两种都试一下。

模型名为什么这么长？能写成 gpt-4o 吗？

不能。模型名前缀（antigravity/、devin/、openai/）代表不同线路，必须完整填写，否则会报“无可用渠道”。复制模型广场里的名字最保险。

在 Cherry Studio 里拉取的模型列表很少？

列表只显示你这个 Key 所在分组能用的模型。default 分组模型较少，新建一个 vip 分组的 Key 就能看到全部。

能用 ChatGPT / Claude 官方网页或 App 吗？

不能。本站提供的是 API，需要在支持自定义接口的第三方工具或你自己的代码里使用。

回答到一半断了 / 很慢？

长回答建议开启流式（stream: true），边生成边显示，体验更好。如果某个模型经常超时，可以换同类其他模型试试。

怎么看自己花了多少钱？

控制台「数据看板」看总体用量，「使用日志」看每一次调用用了哪个模型、多少 token、扣了多少额度。

Key 泄露了怎么办？

立刻在「API 密钥」页面删除或禁用它，再新建一个。建议每个工具单独建一个 Key，并给 Key 设置额度上限，出问题时影响最小。

还是不行，找谁？

把报错信息里的 request id、用的模型名、工具名称发给站长，排查会快很多。请不要把完整的 Key 发出来。
